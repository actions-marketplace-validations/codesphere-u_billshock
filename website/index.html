Frequently asked questions

Clear answers on determinism, false-positive guards, baselines, and CI setup.

Does BillShock require any API keys or third-party packages at runtime?

No. The core auditor in skills/billshock/scripts/billshock.py runs strictly on Python 3.10+ standard library modules with zero network calls and zero external dependencies.

Why won't safe Supabase SSR clients or Django Paginator trigger false positives?

BillShock models framework-safe patterns: JSX apostrophe recovery, Supabase SSR createClient(), Paginator / .count(), Python dict.get() / queue.get(), and AbortSignal.timeout() are recognized natively.

How do legacy repositories adopt BillShock without blocking unrelated PRs?

Generate a fingerprint snapshot once via --write-baseline .billshock-baseline.json, then gate CI using --baseline .billshock-baseline.json --diff HEAD --fail-on high.
