Quick Start

Install BillShock once as an AI Agent Skill, Claude Code plugin, or zero-install uvx CLI, then audit any JS/TS/React/Next.js/Python repo before deploying.

Install Skill or CLI

Recommended for Antigravity, Cursor, Codex, and Claude Code via skills.sh:

npx skills add codesphere-u/billshock

Or install the global CLI with uv or pip:

uv tool install git+https://github.com/codesphere-u/billshock@v1

First Repository Scan

Inside your repository, run BillShock with diff checks enabled and strict score gating:

python3 ~/.agents/skills/billshock/scripts/billshock.py . --diff HEAD --fail-on high --min-score 80

Note: BillShock intentionally refuses scanning your home directory (~) or / unless --allow-home is explicitly passed.

CLI Flags & Exit Codes

Every flag works identically whether invoked via installed billshock or standalone python3 billshock.py.

Flag Reference

FlagDefaultBehavior
--formattextEmit text, markdown, json, or sarif (SARIF 2.1.0).
--diff [REF]HEADInspect git diff against REF (BILL015 / BILL016).
--stagedfalseInspect staged index diff before commit.
--fail-onhighMinimum failing severity: critical, high, medium, low, any, none.
--min-scoreunsetFail if Spend-Safety Score (0–100) falls below threshold.
--write-baselineunsetSave fingerprint snapshot JSON for incremental adoption.
--baselineunsetSuppress pre-existing findings matching saved fingerprints.
--allow-homefalseOverride broad-root safety check when intentionally auditing ~.

Exit Codes

  • 0 — Scan passed `--fail-on` and `--min-score` thresholds (or `--write-baseline` saved cleanly).
  • 1 — One or more findings met `--fail-on` severity or score fell below `--min-score`.
  • 2 — Invalid CLI arguments, missing target directory, or unsafe broad-root invocation (`~` / `/`).

6 Spend-Safety Pillars

Every rule in `BILL001`–`BILL016` maps to one of six concrete runaway-cost failure classes.

Rules Matrix

PillarRulesWhat Is Audited
EFFECT_LOOPBILL001–BILL002Dependency-free React useEffect network loops; sub-1s polling timers.
AI_BOMBBILL003–BILL005Missing max_tokens; paid SDKs in loops; unauthenticated/unthrottled routes.
DB_EGRESSBILL006–BILL008N+1 loop queries; unpaginated findMany/select scans; uncapped Promise.all(map).
RETRY_HANGBILL009–BILL011Unbounded while True loops; timeout-free HTTP; long maxDuration.
LEAK_POOLBILL012–BILL013Per-request DB clients/engines; unbounded module-level caches.
INFRA_CRON & DIFFBILL014–BILL016Sub-5m crons; PR diffs removing rate/token/timeout/limit guards.

Score Calculation

Each unique finding deducts from `100` (`CRITICAL -18`, `HIGH -9`, `MEDIUM -4`, `LOW -1`). Any critical finding caps grade below `SAFE` (`90–100 SAFE`, `70–89 CAUTION`, `<70 BILL SHOCK ALERT`).

Remediation Playbook

Fix cost leaks at the source with drop-in rate limiters, token ceilings, singletons, and pagination instead of adding inline suppressions.

Uncapped LLM Routes

Pair Upstash Ratelimit, explicit max_tokens, and AbortSignal.timeout() in Next.js App Router handlers:

const { success } = await ratelimit.limit(ip);
if (!success) return Response.json({ error: "Too many requests" }, { status: 429 });

const completion = await openai.chat.completions.create(
  { model: "gpt-4o-mini", max_tokens: 512, messages },
  { signal: AbortSignal.timeout(15_000) }
);

Prisma & Python

  • Attach PrismaClient to globalThis in serverless apps (BILL012) and pass explicit take: 50 / cursor pagination (BILL007).
  • Decorate Python caches with @lru_cache(maxsize=256) (BILL013) and always set timeout=5.0 on httpx / requests calls (BILL010).

Git Diff & Baselines

Catch silent regressions even in repositories with legacy tech debt.

PR Regression Mode

billshock . --diff origin/main --fail-on high

Baseline Adoption

billshock . --write-baseline .billshock-baseline.json
billshock . --baseline .billshock-baseline.json --fail-on high

Configuration & Ignores

Exclude generated artifacts cleanly via .billshockignore or .billshock.json.

.billshock.json

{
  "exclude": ["legacy/**"],
  "ignoreRules": ["BILL010"]
}

Inline Suppressions

Attach rule-scoped suppressions only when an out-of-band deadline applies:

// billshock-ignore: BILL010 - unix socket deadline set at transport layer

GitHub Action & SARIF

Drop codesphere-u/billshock@v1 into any pull-request workflow with fetch-depth: 0 so diff checks and SARIF Code Scanning run automatically.

Workflow YAML

- uses: codesphere-u/billshock@v1
  with:
    path: .
    diff: origin/${{ github.base_ref }}
    fail-on: high
    min-score: "80"
    sarif-file: billshock.sarif

Action Outputs

Outputs exposed by action.yml: score (0–100), grade (SAFE, CAUTION, BILL SHOCK ALERT), critical-count, and sarif-file.
