Suppression & CI policy FAQ

When is an inline `billshock-ignore` comment appropriate?

Only when an external transport or gateway enforces limits out of band (for example, a Unix domain socket deadline or internal VPC-only admin job). Prefer fixing the missing max_tokens, dependency array, or pagination cap first.

Does `BILL015` trigger when moving a guardrail cleanly within the same file?

No. BILL015 counts removed vs added guardrails across the diff of a file and only triggers when net protection decreases without replacement.
